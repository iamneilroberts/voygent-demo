Voygent is an MCP server that gives Claude and ChatGPT the tools to plan and price real trips. It started in October 2024 and has been rebuilt more than fifteen times. The pieces worth explaining each get their own post. Right now the catalog is being consolidated from ~70 per-supplier tools into per-domain routers (see Context economics), the supplier adapters run from the edge with no browser farm (The bot-defeat saga), and the client document renders deterministically with zero model tokens.
